# Visual Art Direction Skill

This skill governs the aesthetic language, visual hierarchy, spatial composition, and styling standards of **"What Are We Really Paying For When We Buy a Smartphone?"**.

---

## 1. WHEN TO ACTIVATE

Activate this skill whenever:
- Designing or implementing page layouts, containers, and section boundaries.
- Selecting colors, borders, shadows, and surface elevations.
- Translating the design reference (`zrk.technology`) into consumer electronics components.
- Reviewing UI components to eliminate generic SaaS, dashboard, or e-commerce aesthetics.
- Evaluating visual information density and spatial balance.

---

## 2. AESTHETIC PRINCIPLES

1. **Experimental Technical Editorial:** A synthesis of investigative editorial journalism and precision industrial schematics.
2. **The Reference Ethos (`zrk.technology`):** Study its razor-sharp hairline borders, technical coordinate markers, deep matte surfaces, and typographic restraint. Strictly strip away all military, defense, and weapon imagery; apply this precision visual discipline exclusively to silicon, glass, battery cells, and economic charts.
3. **Structured Density (Anti-Fluff):** The user explicitly rejects excessive empty space. Pack interface regions with purposeful technical data, spec chips, and structured coordinate stamps. Create density through clean 1px hairline grids, not clutter.
4. **Authentic Dark Surfaces:** Never use pitch-black `#000000` for main surfaces. Build depth using calibrated layers of graphite (`#0B0C0E`), charcoal (`#131519`), and steel grey (`#1C1F26`).
5. **Restrained Accent Utility:** The accent color (**Industrial Crimson** `#E63946`) must be applied with surgical precision: active state indicators, telemetry pings, critical data thresholds, and focus rings. Never wash entire backgrounds in accent hues.

---

## 3. MANDATORY STYLING RULES & PROHIBITED PATTERNS

### The Banned Visual Patterns
- **NO Generic SaaS Grids:** Forbid rounded cartoonish cards with heavy drop shadows (`box-shadow: 0 20px 25px rgba(0,0,0,0.1)`).
- **NO Glassmorphism:** Forbid frosted glass panels with heavy blur (`backdrop-filter: blur(20px)`) and thick semi-transparent white borders.
- **NO Gratuitous Gradients:** Forbid multi-color neon gradients (purple-to-blue, pink-to-orange) on text or buttons.
- **NO Floating Blob Animations:** Forbid decorative blurred CSS glowing spheres drifting across the background.
- **NO Excessive Spacing:** Forbid section paddings exceeding `120px` that create barren expanses of empty screen real estate.

### Approved Visual Motifs
- **Hairline Precision Borders:** `1px solid rgba(255, 255, 255, 0.08)` or `1px solid #2A2E38`.
- **Technical Section Identifiers:** Monospaced chapter coordinate stamps (e.g., `// 01.04 / MEMORY_MARKUP_CURVE`).
- **Telemetry Chips:** Compact pill badges featuring uppercase monospace labels with subtle border framing.
- **Subtle Technical Crosshairs:** Corner registration marks (`+`) at major grid intersections.

---

## 5. QUALITY AUDIT CHECKLIST

Before approving any UI view or CSS stylesheet, verify:
- [ ] Is the primary canvas background set to `#0B0C0E` (not pure `#000000` or washed-out blue)?
- [ ] Are borders styled with crisp 1px hairlines (`rgba(255, 255, 255, 0.08)`)?
- [ ] Does the page avoid excessive, purposeless empty whitespace?
- [ ] Are technical chapter stamps and coordinate markers rendered in monospace?
- [ ] Is the accent color (Industrial Crimson) used sparingly for high-value focal points?
- [ ] Are generic rounded card shadows and neon gradients completely absent?
- [ ] Does the layout feel like an authoritative technical publication?

---

## 6. PROJECT CONTEXT & EXPLICIT LIMITATIONS

- **Context:** Visual art direction must elevate the data journalism, not overpower it.
- **Limitations:** Visual embellishments must never obscure chart readability or slow down 3D WebGL rendering.
